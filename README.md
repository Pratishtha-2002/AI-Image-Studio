AI IMAGE STUDIO

* Developed an AI Image Studio web application using HTML, CSS, and JavaScript.
* Built a responsive user interface for entering text prompts and generating AI images.
* Used **Node.js** to develop the backend and handle image generation requests.
* Used **Express.js** to create API endpoints and connect the frontend with the backend.
* Integrated an AI image generation API to generate images from user prompts.
* Implemented loading indicators and error handling for a better user experience.
* Displayed generated images dynamically on the webpage.
* **Technologies Used:** HTML, CSS, JavaScript, Node.js, Express.js, REST API, and AI Image Generation API.
